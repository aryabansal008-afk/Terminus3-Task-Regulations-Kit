# Checklist: Difficulty
(REGULATIONS.md §2)

Difficulty = expected pass rate, not opinion. Never invent a specific pass
rate — reason about which band the task's characteristics suggest.

| Tier | Expected pass rate |
|---|---|
| Frontier | <20% |
| Advanced | 20-50% |
| Core | 50-80% |
| Base | 80-100% |

- [ ] Declared tier in task.toml matches the reasoning above
- [ ] If mismatched, recommended tier + explanation recorded
